# Инструкции для ИИ-агентов SealSign

Читайте README.md, docs/00-source.md, docs/08-decisions.md, docs/11-product-development-plan.md и профильный документ перед изменениями. Проверяйте templates/implementation-status.md и обновляйте его после выполненного этапа; статус done требует доказательств критериев. Готовые задания и handoff — docs/12-agent-execution-guide.md. Рабочий язык документации — русский; идентификаторы кода/контрактов — английский.

- Цель: два класса 0 stamp, 1 signature на внешнем наборе. По указанию пользователя YAT-19 исключён. Подбор источников — docs/09; план к 19.11.2026 — docs/10. Не возвращать YAT-19 как обязательный gate. Фактический объём описать честно; 5 000 из исходной таблицы не достигать копированием.
- Документация сейчас проектная. Не утверждать, что обучение, модель, демо или команды работают без проверки.
- Не выдумывать URL архива, лицензии, результаты, метрики и персональные вклады.
- Manifest и проверенная каноническая разметка — источник истины; negatives и unreviewed различать.
- Split по группам до аугментаций/тайлов; test не использовать для выбора параметров.
- Сохранять исходную геометрию, class mapping и schema/model version. Не дублировать inference в UI/API.
- Не коммитить ZIP, данные, веса, secrets, .env и сырые документы. До публикации примеров проверить права и персональные данные.
- Веса, версии зависимостей и конфигурации фиксировать; сохранять эффективные параметры и checksums.
- Тесты добавлять для реальных рисков: геометрия, leakage, конвертация классов, ошибки входа, контракт API.
- Команды README должны быть реально проверены. Примеры будущих команд явно маркировать.
- Указать выполненные проверки и ограничения в итоговом сообщении. Не называть docs/шаблоны итоговым ГОСТ-отчётом.
- Вопросы, влияющие на данные/ресурсы/объём, записывать в docs/08-decisions.md и уточнять у команды; независимую работу продолжать.

- По указанию пользователя от 06.11.2026 после каждого завершённого этапа делать коммит и push в текущую рабочую ветку. Не включать данные, веса, secrets и приватные образцы. Merge и публичное размещение этим не разрешены.
