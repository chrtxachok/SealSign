# Поиск чистого источника — 15.11.2026

Корпус пока не выбран. Минимум 5 000 независимых исходных страниц сохраняется.
Проверены поисковые результаты Kaggle, первичные публичные карточки Hugging Face
через web tool и README связанного репозитория. Размеры и лицензии ниже —
декларации источников, не результаты скачивания/дедупликации.

## Приоритетный кандидат

https://huggingface.co/datasets/mapo80/stamps

Карточка текущей редакции описывает очищенную сборку из 7 854 изображений с одним
целевым классом stamp и декларирует CC BY 4.0. Предоставляются train.zip, val.zip,
test.zip и dataset.yaml. Старый README связанного GitHub-проекта
https://github.com/mapo80/Stamps-Detection-YoloV9 описывает существенно больший
экспорт; статистики версий смешивать нельзя. Immutable revision пока не установлен.

Выбор следующего кандидата для проверки обусловлен заявленной очисткой источников
и достаточным заявленным объёмом, а не подтверждением качества. Не установлены:
число оригиналов после удаления аугментаций, чистота пикселей, полная разметка
подписей, происхождение и права каждого компонента, безопасность исходного split.
Нужны проверка upstream-условий, version-pinned ZIP/hash/CRC, полный inventory,
декодирование, поиск точных/визуальных дублей и нанесённых меток, пилот и QC двух
классов. Single-class разметка stamp не разрешает считать подписи фоном.

Сеть: текущая политика restricted/enforced не разрешает huggingface.co.
Реальный запрос urllib к https://huggingface.co/api/datasets/mapo80/stamps
через штатный proxy/TLS завершился `Tunnel connection failed: 403 Forbidden`.
Это сетевой запрет среды. Пользователю запрошено добавление huggingface.co;
фактический hostname файлового redirect будет проверен после открытия доступа.
Архивы и изображения этого кандидата не скачивались. Не считать кандидата принятым.

- https://huggingface.co/datasets/hvpu/document-signature-stamp-dataset — карточка
  заявляет 5 714 образцов и page-level классы, но доступ к файлам gated, условия
  нужно принять через аккаунт пользователя. Нет подтверждённых bbox/лицензии и
  числа независимых страниц; этот вариант не выбран. Условия за пользователя
  не принимались, учётные данные не запрашивались.
- Kaggle DocLayNet mirror ayoubelmendoub/doclaynet декларирует CDLA-Permissive-1.0;
  первичный DocLayNet ранее рассмотрен в паспорте. Он решает объём страниц, но
  не даёт готовых печатей/подписей; полная целевая разметка остаётся работой команды.

  минимум реальных независимых страниц. Найденные чисто signature-наборы без stamp
  не принимаются автоматически как двухклассовые.

## DocLayNet-small: загруженный технический пилот — 16.11.2026

Проверен открытый срез [pierreguillou/DocLayNet-small](https://huggingface.co/datasets/pierreguillou/DocLayNet-small)
ревизии `b61d29f477163034001472614dc97fb9614dddea`; карточка среза ссылается на
первичный DocLayNet и CDLA-Permissive-1.0. Срез — переработанное зеркало; условия
и provenance конкретных страниц следует учитывать при принятии и распространении.
Скачанный `dataset_small.zip` (380921569 байт) совпал по SHA-256 с LFS-метаданными:
`85e289b3635b2e17937e201e567d98097173a7b8116daa72dd9e9fb61d738597`.
Архив хранится приватно в `artifacts/data-audit/doclaynet-small/`.

Проверены безопасный inventory, полный CRC, связи изображения с метаданными/PDF
и декодирование 804 изображений 1025×1025: 691 train, 64 val, 49 test. 804
разных image SHA-256 и 804 разных пары `(original_filename, page_no)`; точных
побайтовых совпадений изображений с тремя архивами mapo80 не найдено. Эти
проверки не исключают перекодированные дубли и пересечения содержания.
Категории и хеши — [агрегат](doclaynet-small-audit.json). Воспроизведение из
корня репозитория при наличии четырёх закреплённых архивов:

```console
.venv/bin/python scripts/audit_doclaynet_small.py
```

Обзор 30 train-страниц (seed 42, контактные листы приватны) показал как минимум
одну визуальную подпись; многие страницы представляют обычный печатный текст,
таблицы или иллюстрации. Это не полный просмотр, не проверка отсутствия объектов
и не оценка частоты целевых классов. Исходная разметка относится к структуре
страниц, а не к двум целевым классам. Необходимы визуальная проверка релевантности,
оба класса, дубли и группировка по исходным документам, проверка прав и второй QC.
Ни одна страница этого среза не принята и не добавлена в счётчик S04. Исходный
train/val/test не считается итоговым split. Свободного места после загрузки около
391 MiB; полный архив DocLayNet здесь без расширения хранилища не поместится.
