# Поиск чистого источника — 15.11.2026

Корпус пока не выбран. Минимум 5 000 независимых исходных страниц сохраняется.
Проверены поисковые результаты Kaggle, первичные публичные карточки Hugging Face
через web tool и README связанного репозитория. Размеры и лицензии ниже —
декларации источников, не результаты скачивания/дедупликации.

## Приоритетный кандидат

https://huggingface.co/datasets/mapo80/stamps

Карточка текущей редакции описывает очищенную сборку из 7 854 изображений с одним
целевым классом stamp и декларирует CC BY 4.0. Предоставляются train.zip, val.zip,
test.zip и dataset.yaml. Старый README связанного GitHub-проекта
https://github.com/mapo80/Stamps-Detection-YoloV9 описывает существенно больший
экспорт; статистики версий смешивать нельзя. Immutable revision пока не установлен.

Выбор следующего кандидата для проверки обусловлен заявленной очисткой источников
и достаточным заявленным объёмом, а не подтверждением качества. Не установлены:
число оригиналов после удаления аугментаций, чистота пикселей, полная разметка
подписей, происхождение и права каждого компонента, безопасность исходного split.
Нужны проверка upstream-условий, version-pinned ZIP/hash/CRC, полный inventory,
декодирование, поиск точных/визуальных дублей и нанесённых меток, пилот и QC двух
классов. Single-class разметка stamp не разрешает считать подписи фоном.

Сеть: текущая политика restricted/enforced не разрешает huggingface.co.
Реальный запрос urllib к https://huggingface.co/api/datasets/mapo80/stamps
через штатный proxy/TLS завершился `Tunnel connection failed: 403 Forbidden`.
Это сетевой запрет среды. Пользователю запрошено добавление huggingface.co;
фактический hostname файлового redirect будет проверен после открытия доступа.
Архивы и изображения этого кандидата не скачивались. Не считать кандидата принятым.

  не принимаются автоматически как двухклассовые.

## DocLayNet-small: загруженный технический пилот — 16.11.2026

Проверен открытый срез [pierreguillou/DocLayNet-small](https://huggingface.co/datasets/pierreguillou/DocLayNet-small)
ревизии `b61d29f477163034001472614dc97fb9614dddea`; карточка среза ссылается на
первичный DocLayNet и CDLA-Permissive-1.0. Срез — переработанное зеркало; условия
и provenance конкретных страниц следует учитывать при принятии и распространении.
Скачанный `dataset_small.zip` (380921569 байт) совпал по SHA-256 с LFS-метаданными:
`85e289b3635b2e17937e201e567d98097173a7b8116daa72dd9e9fb61d738597`.
Архив хранится приватно в `artifacts/data-audit/doclaynet-small/`.

Проверены безопасный inventory, полный CRC, связи изображения с метаданными/PDF
и декодирование 804 изображений 1025×1025: 691 train, 64 val, 49 test. 804
разных image SHA-256 и 804 разных пары `(original_filename, page_no)`; точных
побайтовых совпадений изображений с тремя архивами mapo80 не найдено. Эти
проверки не исключают перекодированные дубли и пересечения содержания.
Категории и хеши — [агрегат](doclaynet-small-audit.json). Воспроизведение из
корня репозитория при наличии четырёх закреплённых архивов:

```console
.venv/bin/python scripts/audit_doclaynet_small.py
```

Обзор 30 train-страниц (seed 42, контактные листы приватны) показал как минимум
одну визуальную подпись; многие страницы представляют обычный печатный текст,
таблицы или иллюстрации. Это не полный просмотр, не проверка отсутствия объектов
и не оценка частоты целевых классов. Исходная разметка относится к структуре
страниц, а не к двум целевым классам. Необходимы визуальная проверка релевантности,
оба класса, дубли и группировка по исходным документам, проверка прав и второй QC.
Ни одна страница этого среза не принята и не добавлена в счётчик S04. Исходный
train/val/test не считается итоговым split. Свободного места после загрузки около
391 MiB; полный архив DocLayNet здесь без расширения хранилища не поместится.

## Поиск визуального сходства DocLayNet-small и mapo80

Для всех 804 изображений DocLayNet-small и 7854 mapo80 вычислен 64-битный dHash;
порог расстояния Хэмминга ≤2 задан до просмотра. Сравнены все 322806 пар внутри
DocLayNet-small и 6314616 пар между источниками. Найдены 16 внутренних и 3
межисточниковые пары-кандидата. Среди 19 просмотренных пар 18 различаются по
видимому содержимому; одна пара почти пустых страниц оставлена неоднозначной.
Все три найденные межисточниковые пары имеют разное содержание. Обзор затрагивал
исходные val/test только для проверки идентичности, без настройки модели или
разметки. Решения привязаны к хешу полного приватного CSV; агрегат —
[doclaynet-similarity-review.json](doclaynet-similarity-review.json).

Метод с низким порогом не выявляет все возможные дубли, особенно при изменениях
масштаба, рамки, поворота и наложениях; 18 различий не являются оценкой recall.
Ни одна страница не принята, обучение и split не выполнялись. Приватные листы,
журнал и полный CSV находятся в `artifacts/data-qc/doclaynet-similarity-v1/`.
Команда создаёт новый каталог и откажется перезаписывать его:

```console
.venv/bin/python scripts/audit_doclaynet_similarity.py
```

В метаданных 804 страниц встречаются 511 разных `original_filename`, из них 137
имеют несколько страниц (максимум 53); один и тот же filename не встретился в
разных исходных split. Имя — только подсказка к группировке, не доказательство
полного происхождения. При будущем split страницы одного исходного документа
нельзя распределять между частями. Пригодность, права и полный QC обоих классов
остаются неподтверждёнными.

## Обзор 100 train-страниц DocLayNet-small

Расширен обзор той же детерминированной train-выборки (seed 42): первые 30
страниц совпадают с предыдущей выборкой, всего просмотрены контактные листы 100
страниц. На двух страницах (023 и 088) визуально обнаружены подписи; по исходным
изображениям 1025×1025 подготовлены две черновые bbox класса signature. Обе
рамки проверены на увеличенных изображениях с наложением; это не независимый QC.
Идентификаторы, хеши, координаты и изображения остались в приватном каталоге
`artifacts/data-qc/doclaynet-pilot100-v1/`. Остальные страницы остаются
unreviewed: контактный лист не подтверждает отсутствие мелких объектов.
Число двух обнаруженных страниц — нижняя граница по обзору, а не оценка доли
подписей или печатей во всём корпусе. Страницы и черновые bbox не приняты.

[Агрегат обзора](doclaynet-pilot100-overview.json) фиксирует хеши выборки и
черновика. Выборка воспроизводится командой ниже (каталог результата должен
отсутствовать); повторное создание в отдельном каталоге дало идентичный sample.json.

```console
.venv/bin/python scripts/prepare_doclaynet_pilot100.py
```

Прежде чем использовать страницы, нужны полноценный просмотр обоих классов,
проверка рамок и происхождения, дедупликация и независимый QC. По-прежнему нельзя
считать этот срез автоматически пригодным вкладом в 5000 оригиналов.

## Первый полный просмотр 12 страниц пилота

Страницы 001–010, 023 и 088 выборки осмотрены в исходном разрешении по обоим
классам. В первых десяти целевых объектов не обнаружено при первом просмотре;
на 023 и 088 размечено по одной подписи (включая факсимиле по решению
пользователя). Рамки просмотрены с наложением. Это первый просмотр исполнителя,
а не независимый финальный QC. Десять пустых страниц имеют статус первого
просмотра и не становятся автоматически принятыми negatives.

Двенадцать исходных изображений импортированы в отдельный приватный bundle,
персональные данные и поля источника сохранены вне Git. Зафиксированы хеш
исходного архива, список членов, SHA-256 изображений и метаданные документов;
черновой экспорт привязан к исходному manifest/annotations. Validator экспорта и
validator созданного bundle прошли, применено 2 bbox класса signature и 0 stamp.
Source и first-reviewed bundle хранятся в `artifacts/data-import/doclaynet-pilot12-v1/`;
исходные данные не перезаписаны. [Агрегат](doclaynet-pilot-first-review.json)
фиксирует хеши. Остальные 88 страниц пилота не прошли полный просмотр;
независимый QC, права, дедупликация и групповой split ещё требуются.
