Учебный проект команды Маланин, Солдатов, Клёсов: детекция печатей и подписей. По уточнению пользователя от 05.11.2026 YAT-19 исключён; подбираются внешние данные. Срок — 19.11.2026, основная среда обучения — RTX 4070, резерв — Google Colab.

**Статус:** завершены S04 и S05. На групповом разбиении 2 577 страниц обучен YOLO11n. На расширенном test из 396 страниц получен mAP50–95 0,4662. Итоги приведены в [отчёте об экспериментах](reports/s05-training.md) и [таблице метрик](reports/experiments-s05.csv). [Пример предсказания на синтетической странице](reports/examples/s05-synthetic.png).

## Данные и воспроизводимость

Расширенный корпус построен на [mapo80/stamps](https://huggingface.co/datasets/mapo80/stamps) с проверкой печатей и дополнительной разметкой подписей. Загрузка исходных ZIP сама по себе не воспроизводит разметку. Для сборки того же split нужна приватная копия проверок из [пакета передачи](docs/22-handoff-3000.md). Редакция и состав исходных архивов описаны в [аудите данных](docs/18-mapo80-audit.md). YAT-19 исключён по заданию команды.

## Запуск

### Локальная проверка страницы

Из корня проекта в PowerShell запустите сервер:

```powershell
.\scripts\start-demo.ps1 -NoBrowser
```

Откройте [SealSign](http://127.0.0.1:8765/) в браузере. Выберите JPEG или PNG и
нажмите **Найти печати и подписи**. Кнопка **Открыть пример** загружает
синтетическую страницу для проверки той же модели. Бордовые рамки обозначают
печати, зелёные — подписи. Координаты и оценки детектора можно скачать в JSON.

Скрипт использует имеющуюся локальную среду S05 и пакет модели
`artifacts/s05-runs/bundle-v1`. Для другого компьютера нужны Python 3.11/3.12,
зависимости из [requirements-s05.txt](requirements-s05.txt) и копия пакета модели
от команды. Инференс работает на CPU. Сервер принимает одну страницу
JPEG или PNG до 20 МиБ и 16 Мп. Загруженные изображения обрабатываются в памяти
на этом компьютере.

### Команды разработки

Реализованы справка, версия, настройка логирования и путей, команды `sealsign data import` и `sealsign data validate`. Инструменты сборки корпуса и экспериментов описаны в [протоколе обучения](docs/04-training.md).

Установите [uv](https://docs.astral.sh/uv/getting-started/installation/) версии 0.13.4. Из корня репозитория:

```console
uv python install 3.11
uv sync --locked
uv run --no-sync sealsign --help
uv run --no-sync sealsign --version
uv run --no-sync ruff check .
uv run --no-sync ruff format --check .
uv run --no-sync pytest
```

Проверенная среда и результаты — в [журнале](templates/implementation-status.md). Для обучения на RTX 4070 использованы Python 3.11.18, PyTorch 2.7.1+cu128 и Ultralytics 8.3.228. Проверенный локальный bundle расположен в `artifacts/s05-runs/bundle-v1` внутри рабочего клона команды.

Пути задаются переменными `SEALSIGN_DATA_DIR` и `SEALSIGN_ARTIFACTS_DIR`, по умолчанию `data/` и `artifacts/` относительно рабочего каталога. `.env.example` описывает их; автоматической загрузки `.env` нет. Модуль путей не создаёт каталоги. Данные, веса и секреты хранятся отдельно от кода и исключены из Git. Справка не требует весов, GPU или ML-библиотек.

Уточнение пользователя от 16.11.2026: обязательный минимум 5 000 страниц снят. Используется доступный проверенный корпус; фактическое число уникальных страниц и ограничения качества фиксируются честно (docs/08).

Результат проверки доступных источников S02: [паспорт данных](reports/data/dataset-card.md). Найдены дубли и коллизии ID в резервном SignverOD-зеркале; Kaggle API теперь доступен: основной экспорт содержит 2 452 изображения, лицензия Unknown. Найден дополнительный составной кандидат, требующий аудита и доразметки; экспорт Sig & Stamps v1 скачан и проверен по CRC/SHA-256; права, достаточный объём корпуса и визуальный пилот ещё не подтверждены.


Исследовательский импорт YOLO bbox/polygon, канонический manifest/COCO, проверка
геометрии и preview описаны в [инструкции S03](docs/14-data-import.md).
Проверенная справка: `uv run --no-sync sealsign data import --help`.
Реальные исследовательские прогоны: [агрегированный отчёт](reports/data/import-verification.json).
Отчёт исследовательского импорта описывает состояние до ручного QC.


Для добавления подписей и исправления печатей подготовлен переносимый редактор
пилота: [инструкция](docs/19-annotation-editor.md). Правки экспортируются в JSON
с привязкой к исходным хешам; первый просмотр не закрывает QC всего корпуса.
