## Данные и воспроизводимость

Данные: основной кандидат — [Sig & Stamps](https://universe.roboflow.com/sig-and-stamps/sig-stamps), подтверждённый по ссылке в опубликованном проекте; версия, лицензия и файлы требуют аудита. Резервные источники — SignverOD для подписей и StaVer для печатей. Сравнение, источники и ограничения — в [исследовании данных](docs/09-dataset-research.md). YAT-19 из исходного задания по указанию пользователя не используется. Изображения, ZIP и веса не коммитить. Хранить manifest, SHA-256, разбиение, конфигурации и ссылки на разрешённые артефакты.
