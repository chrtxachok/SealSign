## Данные и воспроизводимость

Данные: основной кандидат — [Sig & Stamps](https://universe.roboflow.com/sig-and-stamps/sig-stamps), подтверждённый по ссылке в опубликованном проекте; версия, лицензия и файлы требуют аудита. Резервные источники — SignverOD для подписей и StaVer для печатей. Сравнение, источники и ограничения — в [исследовании данных](docs/09-dataset-research.md). YAT-19 из исходного задания по указанию пользователя не используется. Изображения, ZIP и веса не коммитить. Хранить manifest, SHA-256, разбиение, конфигурации и ссылки на разрешённые артефакты.

## Запуск

Реализован каркас S01: справка, версия, настройка логирования и путей. Детекция, обучение, API и UI ещё не реализованы.

Установите [uv](https://docs.astral.sh/uv/getting-started/installation/) версии 0.13.4. Из корня репозитория:

```console
uv python install 3.11
uv sync --locked
uv run --no-sync sealsign --help
uv run --no-sync sealsign --version
uv run --no-sync ruff check .
uv run --no-sync ruff format --check .
uv run --no-sync pytest
```

Проверенная среда и результаты — в `templates/implementation-status.md`. CI настроен для Python 3.11/3.12 на Linux и Windows; запуск на пользовательской Windows 11 ещё не проверен.

Пути задаются переменными `SEALSIGN_DATA_DIR` и `SEALSIGN_ARTIFACTS_DIR`, по умолчанию `data/` и `artifacts/` относительно рабочего каталога. `.env.example` описывает их; автоматической загрузки `.env` нет. Модуль путей не создаёт каталоги. Данные, веса и секреты хранятся отдельно от кода и исключены из Git. Справка не требует весов, GPU или ML-библиотек.

Актуальное уточнение 06.11.2026: внешний корпус должен содержать **не менее 5 000 уникальных исходных страниц**. Это обязательный минимум, не достигаемый аугментациями или копированием; прежние формулировки об открытом объёме заменены этим решением (docs/08).

Результат проверки доступных источников S02: [паспорт данных](reports/data/dataset-card.md). Найдены дубли и коллизии ID в резервном SignverOD-зеркале; Kaggle API теперь доступен: основной экспорт содержит 2 452 изображения (меньше 5 000), лицензия Unknown. Найден дополнительный составной кандидат, требующий аудита и доразметки; экспорт Sig & Stamps v1 скачан и проверен по CRC/SHA-256; права, достаточный объём корпуса и визуальный пилот ещё не подтверждены.
