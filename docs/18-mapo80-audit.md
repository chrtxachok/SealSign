## Условия использования и происхождение

README сборки декларирует CC BY 4.0. Первичные публичные Roboflow-карточки
четырёх положительных источников также показывают CC BY 4.0:

- https://universe.roboflow.com/stampa/stamp-detection-4jhgg
- https://universe.roboflow.com/detect-and-classify/yolo-stamp-6jf5w
- https://universe.roboflow.com/marcos-7aslt/stamp-detectation

Карточки просмотрены через web tool. Stampa исходно имеет классы signature/stamp;
текущая сборка оставляет stamp. Связанный GitHub README описывает старую редакцию
с иным размером: не смешивать эти статистики. Происхождение исходных сканов и
история преобразований каждого файла не восстановлены. Условия отрицательных
компонентов RVL-CDIP/FUNSD отдельно ещё не подтверждены; декларация сборки
не заменяет проверку компонентов. Публичное распространение примеров не утверждается.

## Пилот и оставшаяся работа

Из train выбран seed=42, 50 файлов из сортированного списка с последующим shuffle.
Временный sample ZIP сохраняет исходные имена и labels; parent ZIP SHA-256, seed
и перечень выбранных файлов записаны в локальном pilot50-provenance.json.
Sample ZIP импортирован штатным импортёром: 50/50 страниц, 84 stamp bbox,
7 пустых labels, исключений нет. Валидатор bundle exit 0. Пять контактных листов
всех 50 исходных страниц просмотрены агентом: видны подписи, похожие бланки,
повторяющиеся типы печатей; это обзор, не полный QC bbox или второй человеческий
просмотр. По маленькому контактному листу нельзя установить все слабые объекты.
Техническая проверка test проводилась без визуального выбора правил/порогов по test.

Приватный пакет для просмотра — `artifacts/data-qc/mapo80-review50-v1.zip`.
Порядок его изображений задаётся повторным отбором по page_id и отличается от
номеров обзорных контактных листов; эти номера нельзя смешивать. Исправлений
подписей не вносилось, все страницы unreviewed, accepted_for_training=false.

**Решение:** кандидат прошёл полную структурную проверку и не имеет признаков
прежних зелёных overlays по нашему фильтру, но не принят как готовый двухклассовый
корпус. Нужны проверка происхождения, визуальные группы/аугментации, доразметка
подписей на всех используемых страницах и второй QC. Только после этого можно
подтвердить ≥5 000 пригодных оригиналов и строить group split. S04 не завершён.


## Проверка визуального сходства

Все 7 854 изображения дополнительно обработаны тем же 64-битным dHash из
scripts/audit_leakage.py. Попарное сравнение всех файлов при расстоянии ≤2
дало 2 685 кандидатов, из них 868 между исходными split; 737 пар имеют одинаковый
dHash. Это не точные дубли по SHA-256 и не доказанные утечки. Визуальный просмотр
первых трёх train/train пар показал разные короткие письма с похожей компоновкой:
это пример ложных срабатываний. Ни одна группа автоматически не объединялась.

Агрегаты — reports/data/mapo80-similarity-audit.json. CSV содержит только первые
1 000 кандидатных пар в порядке обхода: он усечён, не является полным журналом
группировки. Одноразовый скрипт воспроизведения сохранён локально под
artifacts/data-qc/mapo80-similarity-v1/audit-similarity.py; он использует неизменные
три ZIP фиксированной ревизии и функцию dHash проекта. Остальные пары не
проверены вручную; отсутствие точных байтовых дублей не заменяет этот просмотр.
