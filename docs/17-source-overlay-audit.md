# Проверка нарисованной разметки в исходных пикселях

В пилоте composite-labels-v1 страницы 003 и 037 имеют зелёные подписи `Stamp` и
рамки уже в исходных нормализованных изображениях `pages/`, до нанесения красного
preview. Совпадение SHA-256 pilot PNG и PNG в исходном импортированном bundle для
обеих страниц проверено. Исходные ZIP-пиксели отдельно не сравнивались: в PIL
применяются EXIF transpose и RGB-конвертация. Происхождение нанесённой разметки
и существование чистой версии источника пока не установлены.

Проверенная команда (Python 3.12, Pillow 13.0.0):

```console
.venv/bin/python scripts/audit_green_pixels.py artifacts/data-import/composite-labels-v1 --output artifacts/data-qc/green-pixel-audit-v1
```

Проверяется SHA-256 нормализованных PNG для страниц компонента `stamps`, затем
подсчитываются пиксели R≤40, G≥200, B≤40. Изображение с ≥30 таких пикселей —
кандидат. Среди 292 декодированных страниц компонента (8 исключённых из импорта
не проверялись) 292 кандидата. В 50 исходных PNG пилота composite критерий
сработал для 12 изображений, в 50 пилота Sig & Stamps — для 0; эти два пилотных
подсчёта выполнены однократно по тем же порогам и не являются подсчётом наборов.

Цветовой порог выявляет ярко-зелёные пиксели, но не распознаёт рамку или текст и
может ошибаться на естественных зелёных элементах. Визуально наличие надписей и
рамок подтверждено на 003 и 037, не на всех 292. Полный [агрегированный отчёт](../reports/data/green-pixel-audit.json)
и хеш manifest позволяют воспроизвести результат; приватные page_id и counts находятся
в gitignored `artifacts/data-qc/green-pixel-audit-v1/candidates.csv`.

**Риск:** модель может выучить нанесённые человеком маркеры вместо свойств печати.
До решения об использовании компонента требуется найти исходные изображения без
разметки или исключить заражённые файлы и исследовать оставшиеся. Не удалять линии
автоматически: в том же цвете могут быть настоящие штрихи печати. Метрика на
изображениях с такими же маркерами может завысить качество. Другие компоненты этой
командой не оценивались, отсутствие зелёного цвета не означает чистоту данных.

## Подтверждённые пользователем рамки

Пользователь подтвердил обе фиолетовые рамки для composite pilot 003 и 037.
Исправления внесены в отдельный приватный bundle
`artifacts/data-import/composite-labels-qc-v2/`: для 003 добавлена рамка левой
печати, для 037 изменена существующая нижняя bbox. `qc-corrections.json` фиксирует
предложенные координаты, page_id, hash исходной аннотации/PNG и подтверждение.
Исходный composite-labels-v1 не менялся, изображения и аннотации не коммитятся.
Версии annotation_version двух страниц обновлены, обе страницы остаются unreviewed:
это не проверка других подписей/печатей на странице.

Проверка различий: изменена одна существующая аннотация, добавлена одна, удалений
нет; manifest отличается для двух страниц. Генерированные YOLO labels обновлены.
`sealsign data validate artifacts/data-import/composite-labels-qc-v2` — 1 110
записей manifest, 1 102 изображения, 4 614 аннотаций, accepted_for_training=false.
Восемь ранее исключённых страниц по-прежнему исключены. Аудит пересечений docs/16
построен для manifest версии v1 и не является отчётом для qc-v2; новый bundle
требует отдельного аудита перед split. Корпус и S04 остаются непринятыми.
