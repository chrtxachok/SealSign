# Исходное задание и границы достоверности

Источник: [Компьютерное зрение. Часть 1 / Практика](https://docs.google.com/spreadsheets/d/1f9KuukdU96g6cO8AsPAzo4lpWEw5_JDX2qfB-g83BkA/edit#gid=552945771). Прочитано 05.11.2026; sheetId=552945771. Содержимое таблицы может измениться; ниже текстовая фиксация существенных требований.

## Прямые требования

D8: «Взять для работы один ZIP-пакет YAT-19 объёмом 5 000 страниц.В одном пакете найти и разметить 2 типа объектов: печать, подпись. Обучить детектор.»

C8: «Поиск печатей и подписей»; B8: № 4. F8:H8: Маланин, Солдатов, Клёсов. K8: «1 сдана (посмотреть другие варианты архивов)». Это замечание требует уточнения у команды: оно не доказывает пригодность какого-либо архива и не разрешает заменять основной набор смесью архивов.

Гиперссылка внутри D8: https://huggingface.co/datasets/konstantinkozhin/YAT-19 . Страница датасета в рамках подготовки документов не исследована; состав, объём объектов и лицензия не подтверждены.

C2: работа командой из 2–3 человек; отчёт по ГОСТу и GitHub-репозиторий. Отчёт: задание, цель, состав; данные и подготовка; метод и модель; пошаговые эксперименты; метрики и примеры; ошибки и выводы; вклад каждого. Репозиторий: README и запуск; ссылка на данные; код подготовки, обучения, инференса; зависимости и конфигурации; таблица метрик и примеры; ссылка на веса при наличии. Большие файлы и датасеты не загружать в GitHub. Основные этапы должны воспроизводиться.

## Трассировка

| ID | Требование источника | Реализация/доказательство |
|---|---|---|
| SRC-01 | Один ZIP, 5 000 страниц | manifest, checksum, паспорт архива; docs/03 |
| SRC-02 | Найти и разметить два типа | инструкция, журнал QC, экспорт аннотаций |
| SRC-03 | Обучить детектор | конфигурация, логи, checkpoint, docs/04 |
| SRC-04 | Воспроизводимый репозиторий | lock, CLI, smoke run на чистой среде |
| SRC-05 | Метрики, результаты, ошибки | протокол docs/07, CSV экспериментов |
| SRC-06 | Отчёт по ГОСТу и вклад | templates/report.md, журнал задач |
| SRC-07 | Рассмотреть другие архивы | протокол пилотного сравнения и решение |

API, UI, Docker, bounding boxes, выбор YOLO и численные целевые метрики — проектные предложения, а не цитаты преподавателя. Настоящий пакет описывает будущую разработку; он не является итоговым отчётом об обучении.

## Изменение постановки пользователем — 05.11.2026

Пользователь сообщил, что YAT-19 непригоден, первый отчёт не нужен, и поручил самостоятельно подобрать обучающие данные. Это актуальное рабочее указание, приоритетное для агентов. Срок — через две недели (19.11.2026); обучение — RTX 4070 либо Colab; требований к демо нет. SRC-01 и SRC-07 теперь исторические требования исходника: реализуется внешний корпус с раскрытым отличием. Объём заменяющего набора и согласование изменения с преподавателем не подтверждены. Остальные требования к двум классам, обучению, воспроизводимости и отчёту сохраняются.
