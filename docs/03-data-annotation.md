# Данные, отбор архива и разметка

## Сначала подтвердить пригодность

1. По указанию пользователя YAT-19 и первый отчёт не запрашивать повторно. Начать с Sig & Stamps, источники и резервный путь — docs/09-dataset-research.md.
2. Проверить dataset card, лицензию, точную версию, файлы, классы и полноту разметки обоих классов.
3. Сравнить кандидаты по воспроизводимой пилотной выборке до 200 страниц каждого, равномерно по набору с фиксированным seed. Итоговый corpus manifest фиксирует все источники и роль каждого.
4. Для каждого кандидата записать: URL, revision, filename, bytes, SHA-256, число страниц, доли читаемых страниц, число stamp/signature/negatives, разнообразие, качество сканов. Долю положительных страниц сопровождать размером выборки; не экстраполировать число объектов как факт.
5. Выбрать версию набора с реальными представителями обоих классов и достаточным разнообразием. Если единый набор непригоден, использовать резервный составной корпус только с явным provenance и доразметкой отсутствующих классов. Смена данных разрешена пользователем; соответствие изменённого объёма исходному заданию описать в отчёте.

Порог пилотной готовности (предложение): хотя бы 30 экземпляров каждого класса и несколько независимых документов; это основание начать аудит, не гарантия качества. До полного обучения оценить доступность обоих классов в каждой части split. Для редкого класса допустимы иные доли split с документированным решением, без утечки групп.

## Учёт всех исходных страниц

Manifest JSONL: page_id, archive_id, relative_path, source_document_id, group_id, sha256, width, height, decode_status, duplicate_group, review_status, annotation_version, split, exclusion_reason. Пути относительные; page_id стабилен от archive_id и пути. Сохранить исходную контрольную сумму отдельно от производных файлов. Защитить распаковку от ../, абсолютных путей, symlink и чрезмерного суммарного объёма.

Количество исходных страниц фиксируется фактически. После уточнения 06.11.2026 обязательный минимум — 5 000 уникальных исходных страниц; фиктивные страницы недопустимы. Повреждения и дубли не удалять из учёта: фиксировать исключения и фактическое число используемых страниц. Не доводить объём до 5 000 искусственным копированием: отдельно отразить отклонение от исходного задания. Негативные страницы после просмотра имеют reviewed_empty, непроверенные — unreviewed; пустая YOLO-разметка не подтверждает просмотр.

## Словарь классов

| ID | Класс | Включать | Не включать |
|---|---|---|---|
| 0 | stamp / печать | видимый оттиск печати, включая слабый/частичный | печатную эмблему, круглый логотип, рамку, типографский знак |
| 1 | signature / подпись | отдельную рукописную подпись/росчерк | ФИО печатным текстом, обычные рукописные слова, пустую линию подписи |

Служебные штампы, факсимиле, инициалы и трудноотличимые росчерки помечать disputed до согласования. Предложение: служебные штампы включать в stamp только после явного решения и одинаково во всех split. Текст «подпись» не является объектом. Визуально неотличимое факсимиле нельзя надёжно классифицировать по подлинности; задача только визуальная.

## Правила рамок

Одна axis-aligned bbox на один визуально отдельный объект, плотно по видимым штрихам без соседнего текста; не достраивать невидимую часть за краем. Включать весь видимый оттиск, даже если он перекрывает текст. Перекрывающиеся печать и подпись — две независимые рамки разных классов. Для разорванной, но связной подписи — одна рамка по всему росчерку. Для нескольких экземпляров — отдельные рамки. Не отбрасывать объект только из-за малого размера. Слишком неоднозначные области направлять на adjudication, сохранять причину и решение.

Канонический обмен: COCO bbox=[x,y,w,h] в пикселях, category_id 0/1 в нашем экспорте; если инструмент требует 1-based ID, явно remap при импорте. YOLO training: class cx/W cy/H w/W h/H, все значения в [0,1], размер >0. Контрольный COCO export и manifest — источник истины, YOLO — производный. Изображение и аннотация должны иметь одну ориентацию; после EXIF преобразовать и рамки.

## Процесс и QC

Инструмент: CVAT или Label Studio, окончательно выбрать по доступу команды. Пилот: все участники независимо размечают общие 50 страниц; обсуждают расхождения, фиксируют примеры и правила v1. Затем распределяют все страницы, просматривают в масштабе, достаточном для слабых штрихов. Предсказания могут ускорять разметку только с полной человеческой проверкой; test размечать без подсказок исследуемой модели.

Второй проверяющий: все positive и disputed страницы; случайные 10% reviewed_empty. Если найдены пропуски — расширить повторную проверку соответствующей партии до полной. До финальной оценки test полностью проверяет второй участник. Разногласия: matching по классу/IoU≥0.5, отчёт unmatched и IoU matched; окончательное решение человека с записью. Эти значения оценивают согласованность, а не качество модели.

Автопроверки: класс, конечность координат, границы, ненулевая площадь, повтор рамки, существование файла, отсутствие orphan labels, согласованность width/height. QC-гейт: нет unresolved disputed и unreviewed в используемом корпусе, нет невалидных рамок, отрицательные явно подтверждены.

## Разбиение

Предложение train/val/test=70/15/15 по страницам приблизительно, seed=42. Группировать по документу, серии/источнику и семействам дублей; все связанные страницы и near duplicates в одном split. Если document_id отсутствует, восстановить группы из структуры архива и визуального сходства, проверить вручную; случайное page split — только явно обоснованное исключение. Отразить риск одинаковых шаблонов в разных группах. Проверять exact hash и perceptual similarities между split, спорные пары просматривать.

Разделить до crop/tiles/augment; ни один производный фрагмент не меняет split исходной страницы. Балансировать наличие обоих классов на уровне групп, не копировать редкие объекты в val/test. Test фиксируется и не используется для настройки порогов, выбора модели или просмотра ошибок в ходе экспериментов. После финальной оценки изменения считаются новой исследовательской итерацией с раскрытием использования test.

Актуальное уточнение 06.11.2026: внешний корпус должен содержать **не менее 5 000 уникальных исходных страниц**. Это обязательный минимум, не достигаемый аугментациями или копированием; прежние формулировки об открытом объёме заменены этим решением (docs/08).
