## Риски

| Риск | Как обнаружить | Действие |
|---|---|---|
| Неполная разметка одного из классов во внешнем наборе | пилот и полный аудит | сменить источник или дополнить разметку обоих классов |
| Мало экземпляров редкого класса | support по независимым группам | расширить аудит, не копировать в test |
| Ошибки и неоднозначность разметки | двойной просмотр/QC | инструкция, adjudication, version bump |
| Утечка шаблонов/дублей | group/hash/perceptual checks | перегруппировать до обучения |
| Потеря мелких объектов | recall по размерам | resolution/tiles ablation |
| Не хватает VRAM/времени | smoke benchmark и пилот труда | batch/модель/бюджет; не урезать задание молча |
| Недоступны веса на защите | offline rehearsal | локальный bundle и checksum |
| Лицензионные ограничения | dataset/model cards | выбрать совместимую реализацию, ограничить публикацию |
| Документы содержат персональные данные | review примеров | локальное хранение, разрешённые примеры |
| Завышенное качество из-за test tuning | журнал экспериментов | выбор по val, test freeze |
