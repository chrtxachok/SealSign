# Исследовательский аудит пересечений S04

`scripts/audit_leakage.py` проверяет импортированные bundle и готовит пары страниц
для проверки группировки. Команда не меняет аннотации или manifest, не создаёт split
и не разрешает обучение. Используются исходные метки split только как диагностический
признак; `valid` и `val` рассматриваются как одно значение.

Проверенная команда из корня проекта, Python 3.12 и Pillow 13.0.0 из uv.lock:

```console
.venv/bin/python scripts/audit_leakage.py artifacts/data-import/sig-stamps-v1 artifacts/data-import/composite-labels-v1 --output artifacts/data-qc/leakage-audit-v1 --threshold 2
```

Для каждой не исключённой страницы проверяются путь и SHA-256 нормализованного PNG,
затем вычисляется 64-битный dHash на grayscale 9×8. Рассматриваются все пары между
источниками и пары внутри одного источника с разными исходными split. В отчёт
попадают пары с одинаковым SHA-256 исходного файла, одинаковым SHA-256 PNG,
одинаковым префиксом имени до `.rf.` внутри одного архива или расстоянием dHash ≤2.
Префикс — только эвристика: типовые имена могут совпадать у разных документов.
Сходство dHash, особенно на пустых и похожих бланках, не доказывает дублирование;
аугментации, повороты и повторные сканы могут остаться незамеченными.

`report.json` содержит агрегаты, версии параметров и хеши входов. Локальный
`candidate-pairs.csv` содержит page_id и split для ручной проверки; каждое совпадение
имеет `review_status=unreviewed`. CSV, исходные изображения и аннотации остаются в
`artifacts/data-qc/` и не публикуются. Агрегированный отчёт —
[leakage-audit.json](../reports/data/leakage-audit.json).

Аудит рассмотрел 3 554 импортированные страницы; 8 исключённых страниц и 16 000
неимпортированных RVL-CDIP в него не вошли. Найдено 3 пары исходных побайтовых
дублей между train и val составного набора; исходный split использовать нельзя.
Найдено 1 545 пар с общим префиксом внутри Sig & Stamps на разных исходных split
(176 разных page_id); проверить вручную, поскольку префикс не устанавливает
идентичность. 225 пар имели dHash distance ≤2, из них 115 между источниками.
Категории пар пересекаются и не суммируются. Эти величины не являются числом
утечек или независимых оригиналов. Разметку test не просматривали для настройки;
хеши и признаки сходства используются только для контроля возможной утечки.

Ограничения: пары внутри одного исходного split того же архива в CSV не включены,
поэтому список не является готовой группировкой для нового split. Группы точных
SHA-256 и одинаковых префиксов подсчитаны отдельно по всем страницам. Для S04
нужны проверенные группы документов и дублей (включая внутри split), ручное
разрешение кандидатов, QC всех страниц и новый split до аугментаций. Никакие
кандидаты автоматически не объединяются и не маркируются проверенными.

Для mapo80/stamps добавлен отдельный поиск повторных фонов с маскированием
печатей и сравнением тёмных штрихов, включая пары внутри split:
[проверка оригинальности](21-background-originality-audit.md). Его кандидатный
граф не заменяет проверенные группы и не устанавливает число оригиналов.
