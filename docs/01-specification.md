# Техническое задание v0.1

Статус: проект с учётом уточнения пользователя 05.11.2026. YAT-19 исключён; внешние данные подбирает исполнитель. Дедлайн 19.11.2026, RTX 4070 основная среда, Colab резерв. Требование 5 000 страниц остаётся в исходной таблице, но для заменяющего набора количество ещё нужно согласовать; не дополнять его копиями. Обязательные требования обозначены SRC в исходнике; FR/NFR ниже — выбранные проектные контракты. Предмет: локализация визуальных оттисков печати и рукописных подписей на документных страницах.

## Назначение и сценарии

Пользователь передаёт страницу, получает список рамок двух классов и изображение с наложением. Исследователь воспроизводит подготовку, обучение и оценку. На защите команда показывает положительные, отрицательные и сложные страницы, измеренные показатели и ошибки.

Распознавание текста, установление автора подписи, проверка подлинности и юридической силы, сегментация контура не входят в MVP. Отсутствие детекции не доказывает отсутствие объекта. Рамки не являются проверкой подлинности.

## Функции

| ID | Поведение | Условие приёмки |
|---|---|---|
| FR-01 | Импорт зафиксированной версии внешнего набора | все исходные страницы учтены; фактическое N, checksum и provenance |
| FR-02 | Инвентаризация и аудит | повреждения, дубли, размеры, распределение объектов отражены в отчёте |
| FR-03 | Разметка stamp/signature | каждая страница проверена человеком; negatives отличимы от unreviewed |
| FR-04 | Подготовка train/val/test | стабильный split по группам; нет общих групп и дублей |
| FR-05 | Обучение | сохранены effective config, seed, окружение, логи и лучший checkpoint |
| FR-06 | Оценка | поклассовые AP/P/R, mAP, FN/FP, время, число страниц и объектов |
| FR-07 | CLI инференса | JSON и overlay; пустой detections — корректный успех |
| FR-08 | Демонстрация | UI использует тот же inference core; видны версия модели и ошибки |
| FR-09 | Переносимый результат | схема v1; исходные координаты и confidence сохраняются |

## Входы и выходы

MVP: JPEG/PNG, RGB/серый канал, один файл — одна страница. TIFF, PDF и пакетные ZIP на входе сервиса — последующие адаптеры после согласования. Архивы обучающих данных обрабатывает отдельный офлайн импортёр. Декодирование нормализует EXIF; координаты результата относятся к нормализованному изображению с width/height из ответа. Для PDF позже обязательно хранить DPI и преобразование в координаты страницы.

Начальные ограничения демо: 20 MB/файл, не более 40 млн пикселей, одна активная обработка на worker. Эти значения настраиваемые, проверяются до полного декодирования по возможности; декомпрессионные бомбы блокируются. Ошибки: неподдерживаемый формат, повреждённый файл, превышение лимита, недоступная модель, timeout. Успешный ответ не подменяется фиктивными рамками.

## Нефункциональные требования

Воспроизводимость: версии данных/аннотаций/кода/весов и зависимости фиксируются. Seed=42 по умолчанию; недетерминированные CUDA-операции указываются. CPU инференс обязателен как переносимый режим; скорость и память измеряются, обещания реального времени не даются. Обучение на RTX 4070 пользователя; точный VRAM и ОС проверить перед запуском. Colab — резерв с переменным типом GPU и лимитами сессии.

Конфиденциальность: локальная обработка по умолчанию, без внешних AI API. Не писать содержимое документов в логи. Временные загрузки удалять после ответа и при ошибке; очищать остатки при старте. Публичные примеры — только с правом публикации и после проверки персональных данных.

## Критерии завершения

Обязательна измеренная оценка, даже если качество ниже целей. Предложение инженерных целей: AP50 каждого класса ≥0.75, recall каждого класса ≥0.80 при выбранном на val пороге. Это не требования преподавателя и не достигнутые значения; согласовать после пилота. Метрики на малой выборке публиковать с количеством объектов и интервалами неопределённости. Срок — 19.11.2026. Численные SLA и правила ГОСТа пока открыты. Не менять критерии задним числом без записи решения.
